# GitHub README Designer

A free, frontend-only React application for discovering and redesigning public GitHub repository README files.

## Technology

- React + Vite
- Tailwind CSS
- React Router
- GitHub REST API
- React Markdown
- remark-gfm
- rehype-highlight
- rehype-sanitize
- Lucide React

## Development

```bash
npm install
npm run dev
```

## Verification

```bash
npm run lint
npm run build
```
